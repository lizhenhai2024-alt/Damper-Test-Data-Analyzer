# V0.8.19 使用说明

Windows 构建成品的文件名包含版本号。本版 EXE 为 `Damper_Test_Data_Analyzer_V0.8.19.exe`，GitHub Actions 中对应的 Artifact 为 `Damper_Test_Data_Analyzer_V0.8.19_Windows`，便于下载后直接识别版本。

## 显示缩放与响应图

软件使用 Qt 的 DPI 感知布局。在 Windows 100% 和 150% 缩放下，标注和坐标轴标题均使用相同的 10 pt 正常字重，系统负责转换显示像素，不再对标注额外放大。窗口较窄时工具栏自动换行；高度不足时，可滚动查看完整的三个同步响应图。

响应图标注使用透明背景。电流触发标签不再固定在左侧，而是显示在实际触发时间与电流曲线的交点；下标取自“电流触发”设置，例如设置为 25% 时显示 I₂₅%。I₁₀₀% 保持为终值参考。载荷阈值标签位于载荷图左侧，所有参考虚线保持连续。载荷阈值标签始终保持与各自水平虚线相同的垂直顺序：负压缩行程中起始 F 阈值在上、F₁₀₀% 在下，F₁₀₀% 必须位于 F₉₀% 下方；正复原行程中起始 F 阈值在下、F₁₀₀% 在上，F₁₀₀% 必须位于 F₉₀% 上方。电流图的触发时刻、载荷图的触发及响应时刻，均以圆点标记竖虚线与实测曲线的插值交点。载荷响应时间交替分布在曲线两侧；视图缩放或尺寸变化后会再次避让其它文字。

“起始载荷阈值”默认 1%，允许在 0.1%～62.9% 范围内调整。起始 F 标签和起始 t 标签始终使用设置值对应的下标，例如 5% 显示为 F₅% 与 `t₅% = xx ms`。F 起始阈值与 F₆₃% 各有一个显示复选框；取消勾选会同时隐藏该阈值的水平线、响应时刻竖线、交点及时间文字，但不改变内部计算和结果表。改变阈值后完成编辑会自动重新分析当前数据。

响应时间始终为相应力阈值交点时刻减去当前电流触发比例的交点时刻。使用默认 10% 设置时计时基准为 I₁₀%；改变为其他比例后，图形、结果设置和计时基准说明同步更新。

“响应图”可选择“三联响应图”或“双Y轴 I₁₀%—I₉₀%”。双 Y 轴模式以时间为 X 轴，左侧蓝色 Y 轴和蓝色曲线表示电流（A），右侧红色 Y 轴和红色曲线表示阻尼力（kN）。程序按当前事件的起始与终止电流计算固定的 I₁₀% 和 I₉₀% 电平，在线性插值后的两个穿越时刻绘制两条竖虚线。两个时刻在电流曲线上各有一个蓝色圆点，在阻尼力曲线上各有一个红色圆点，并显示相应的阻尼力值。图中的 `Δt(I₁₀%→I₉₀%)` 等于 I₉₀% 穿越时刻减去 I₁₀% 穿越时刻。

结果数据与 Excel 的 `Response Summary` 同时包含 `Current 10% A`、`Current 90% A`、`I10 Crossing Time s`、`I90 Crossing Time s` 和 `Current Response I10-I90 ms`，便于复核计算和后续统计。该固定 10%—90% 电流响应指标独立于上方可调的载荷响应计时基准。

## 响应客户速度预设

响应时间页面的“规范”列表提供以下目标速度预设：

- 红旗：0.131、0.262、0.524、1.047 m/s。
- 国内主机：0.1、0.3、0.6 m/s。
- 零跑：0.15、0.70 m/s。
- BMW：0.131、0.524、1.048 m/s。
- Audi：0.052、0.131、0.262、0.524 m/s。

切规范后，目标速度输入框会自动更新。输入框仍可编辑，因此其它客户或非标准工况可以直接输入任意正有限速度。红旗、国内主机和零跑当前使用公共响应时间提取逻辑以及界面设置的电流触发比例、起始载荷阈值和 t₉₀% 限值；仅根据已提供信息设置速度点，不推断其它客户专用判定规则。

## 电流—阻尼力与分组迟滞图

主界面“评价设置”的评价方法不再提供 Audi，仅保留“窗口均值”和“目标位移穿越插值”，默认使用“窗口均值”。窗口均值的基准固定为“总行程全宽”，因此界面不再显示没有选择意义的“窗口基准”；窗口比例仍可调整。响应时间与迟滞是独立的专项分析模块，其 BMW/Audi 客户规范选择继续保留。

1. 从公共数据源打开包含完整循环和电流平台的数据，选择 BMW 或 Audi 评价规则。
2. 设置速度分组容差，默认 3%。程序根据中心行程实测速度分组，容差表示相对组内最低速度的最大偏差。速度点相近时，应减小容差；分组值会写入导出设置。
3. 点击“分析迟滞”。每个速度组独立进行原有 BMW 升/降电流配对或 Audi KFM 前后平台计算，不跨速度求均值。
4. 首图“全部速度：电流—阻尼力”叠加各速度曲线。纵轴统一为“压缩<--阻尼力(N)-->复原”，复原显示正阻尼幅值、压缩显示负阻尼幅值。原始数据及导出数值保留其原始符号。
5. 图形选择器自动生成各速度的电流—阻尼力迟滞图，以及各电流的速度—阻尼力图。所有迟滞试验曲线均使用连续实线段，不再显示数据点圆点；相邻工况点强制连续连接并启用抗锯齿，避免视觉上出现虚线或断线。不同速度、电流和方向通过颜色与图例区分。BMW 仍保留升/降电流分组，Audi 仍按实测平台先后连接并保留 KFM 往返路径。
6. 图形选择器新增“电流—迟滞力柱状图”：横轴为电流，纵轴为迟滞力（N），按实测速度及压缩/复原方向分组，每根柱顶显示取整后的迟滞力值。该图同样支持当前图 PNG 导出，并自动写入迟滞 Excel 的图形工作表。
7. “结果数据”页保留汇总和工况明细；Excel 导出包含所有分组图，PNG 导出当前选中图，图像按菜单栏选择的分辨率写入像素密度信息。

迟滞结果中的 `Force N`、`Abs Force N`、升/降电流阻尼力、参考阻尼力和迟滞力均按整数显示并使用 Excel 整数格式。该规则只影响显示与导出格式，内部分析仍使用完整浮点精度。

要比较不同速度，可以点击“加载多速度迟滞数据…”并一次选择各速度的原始文件；也可以点击“扫描迟滞数据文件夹…”，程序会递归扫描所选文件夹及全部子文件夹中的 `.dat` 文件。程序会隔离每个文件的 Block ID，再按中心行程实测速度统一分组；只导入一个文件时，图中只能出现一个实测速度。导出前程序会自动切换到迟滞图形页并重算纵轴范围，保证压缩方向完整显示。

只有输入数据中真实存在的速度、电流与方向才会生成曲线。未配对工况可显示实测点，但不会补造迟滞值；单一电流只有一个速度时，其速度图只有实测点。响应试验中的电流跳变数据不等于完整的电流扫描迟滞试验。

## 其它功能

- 每次导入新数据后，【图形】的 X/Y 轴选择列表只显示原始文件中实际存在且含有效数值的通道列；Block ID、Source Row、分析派生列和全空列不进入列表。默认以第 1 个通道为 X 轴并选择其余通道作为 Y 轴。Y 轴已选字段文字使用对应曲线的颜色，改变选择后颜色立即同步；重新分析同一文件时保留手动选择。
- 目标速度与客户规则独立，可输入 0.1、0.3、0.6、1.0 m/s 等正有限速度点。
- 气体反弹力支持加上或减去，原始载荷不覆盖。
- t₉₀% 和迟滞限值未设置时，不自动判定客户合格与否。
- 菜单栏【导出 → 图片分辨率】可选 150、300、600 PPI，默认 300 PPI。独立 PNG 与 Excel 内嵌图均使用当前选择；600 PPI 时至少按 5000 px 宽度渲染，适用于报告与打印。PNG 是无损位图，清晰度由实际像素尺寸和查看方式共同决定，并非 PNG 格式压缩造成。PPI 表示打印密度：300 PPI 适合常规报告，600 PPI 适合打印或裁切。聊天软件、文档预览和屏幕缩略图通常会先缩小原图，细线与浅色虚线会因此看起来较淡；检查导出质量时，请在图片查看器中按 100% 比例打开原始 PNG。
