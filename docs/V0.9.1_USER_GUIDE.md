# V0.9.1 全电流分析使用说明

## 数据加载

1. 打开“全电流分析”页，选择多个 MTS `.PVP` 或 CTW `.dctw` 文件，也可以递归扫描文件夹及子文件夹。
2. 电流 A 只从文件名自动识别，例如 `0.4.pvp`、`2#-0.3A-1.dctw`、`20260609 FR30 0.3-A-2.pvp`。数字与 A 之间可无分隔符，也可使用连字符或下划线。电流列不可手工修改；无法识别电流的文件不会加载。
3. 重复或异常测量可通过“移除所选数据”排除。软件只移除当前列表记录，不删除原始文件。同电流、速度和方向的保留测量按均值汇总。
4. 软电流默认 0.3 A、硬电流默认 1.6 A，可在点击“全电流分析”前调整。所选电流档必须存在于已加载文件中。

## 计算与图表

- 每个不高于 1.047 m/s 的速度段使用最后一个完整循环，在行程中心总行程 10% 窗口分别提取复原最大力和压缩最小力。
- 第20项按照 `F_normalized = (|F_i| - |F_soft|) / (|F_hard| - |F_soft|)` 计算，复原显示为正、压缩显示为负；黑色45°虚线表示软电流至硬电流之间的理想线性关系。
- 第21项在一个图中显示：左 Y 轴柱形为阻尼力范围 `|F_hard| - |F_soft|`，右 Y 轴折线为放大倍数 `|F_hard| / |F_soft|`。压缩范围显示为负值，所有柱形和折线点均标注计算值。
- F-V 图按电流显示阻尼力随速度变化；F-I 图按速度显示阻尼力随电流变化。两个方向共用坐标轴，复原为正、压缩为负。
- F-V 数据表以电流为行，先排列各复原速度列，再排列各压缩速度列；阻尼力显示为整数。
- 第20项、第21项、F-V 和 F-I 图固定使用白色背景。

## Excel 导出

导出的工作簿包含 `20 Current-Force Linearity`、`21 Spread-Amplification`、`F-V Data`、`Run Detail`、`Source Files` 和 `Settings`。设置页记录软/硬电流、速度上限、评价窗口和电流来源。
