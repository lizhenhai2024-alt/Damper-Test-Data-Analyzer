# V0.9.0 使用说明

## Audi 第20项：电流—阻尼力线性

1. 打开“第20/21项”页，点击“添加 PVP / DCTW 文件…”选择不同电流的试验文件，或点击“递归扫描文件夹…”一次读取文件夹和全部子文件夹。
2. 检查文件列表中的“电流 A”。程序支持 `0.4.pvp`、`2#-0.3A-1.dctw` 等命名；未识别或需要修正时，可双击电流单元格输入实际值。
3. 对重复或异常测量，选中一行或多行后点击“移除所选数据”。该操作只改变当前分析列表，绝不删除原始文件。
4. 点击“分析第20/21项”。程序读取每个文件内不高于 1.047 m/s 的速度段，选取最后一个完整循环，并在行程中心总行程 10% 窗口内分别取得复原最大力与压缩最小力。
5. 每个速度和方向分别寻找最软与最硬阻尼力，计算：

   `F_normalized = (|F_i| - |F_soft|) / (|F_hard| - |F_soft|)`

   图中复原为正、压缩为负。结果数据同时给出线性拟合 R²、最大拟合偏差、软/硬电流和软/硬阻尼力。

## Audi 第21项：阻尼力范围与放大倍数

每个速度和方向分别计算：

- 阻尼力范围：`ΔF = |F_hard| - |F_soft|`；图中复原为正、压缩为负。
- 放大倍数：`V = |F_hard| / |F_soft|`；压缩和复原均显示为正值。

软件不推断项目限值。客户项目的判定限值应以受控技术文件为准。

## 文件格式与重复测量

- `.PVP`：读取 MTS/Roehrig Shock 的 OLE Session 数据，一个文件可包含多个速度段。
- `.dctw`：读取 CTW Probe 的 Bond Compact Binary 压缩数据；使用文件头中的通道名称、单位和传感器标定表把原始力信号换算为 N。
- 同一文件路径不会重复加入；不同路径下的重复测量会分别保留。相同电流、速度和方向的保留结果按均值汇总，并输出重复次数与标准差。
- Excel 导出含 `20 Current-Force Linearity`、`21 Spread-Amplification`、`Run Detail`、`Source Files` 和 `Settings`。
